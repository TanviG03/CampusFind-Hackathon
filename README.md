# CampusFind – Smart Campus Lost & Found

CampusFind is a mobile application designed to help students report, search, and recover lost and found items within a college campus.

It provides a centralized platform where students can report lost items, report items they have found, search available reports, and connect with the concerned person for item recovery.

## 📌 Problem Statement

Every day, students lose items such as ID cards, wallets, keys, books, earphones, water bottles, and other personal belongings inside college campuses.

Currently, students often depend on WhatsApp groups, social media, or word-of-mouth to find their lost items. These methods are not centralized and can make it difficult to efficiently connect lost and found items.

CampusFind aims to provide a simple and centralized digital solution for managing lost and found items within a campus.

## 💡 Solution

CampusFind provides a single platform where students can:

* Report lost items
* Report found items
* Search for lost or found items
* Filter available reports
* View item details
* Contact or claim an item
* Track their submitted reports
* Mark recovered items

## ✨ Key Features

### 👤 User Authentication

* Student registration and login
* Simple and user-friendly interface

### 🔍 Browse & Search

* Browse lost and found items
* Search for specific items
* Filter available reports

### 📢 Report Lost Item

Students can submit details about an item they have lost.

### 📦 Report Found Item

Students can report an item they have found so that the owner can identify and recover it.

### 📄 Item Details

Users can view detailed information about a reported item.

### 🤝 Claim / Contact

Users can contact the concerned person regarding a lost or found item.

### 📋 My Reports

Students can view and manage the items they have reported.

### ✅ Recovery Status

Items can be marked as recovered once they are successfully returned to their owner.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Expo

### 1. Clone the Repository

```bash
git clone https://github.com/TanviG03/CampusFind-Hackathon.git
```

### 2. Navigate to the Project

```bash
cd CampusFind-Hackathon
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
npm start
```

Expo will start the development server and provide options to run the application on a mobile device, emulator, or web browser.
